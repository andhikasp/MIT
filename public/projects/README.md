# Projects Photos

Silakan tambahkan foto-foto proyek di folder ini dengan nama file berikut:

- `civil-work.jpg` - Foto untuk Pekerjaan Sipil Pembangunan Menara (Civil Work)
- `tower-accessories.jpg` - Foto untuk Instalasi dan Pemasangan Aksesori Menara
- `electrical-system.jpg` - Foto untuk Sistem Kelistrikan dan Jaringan Daya
- `maintenance.jpg` - Foto untuk Pemeliharaan Perangkat & Tower
- `install-dismantle.jpg` - Foto untuk Instal dan Dismantle Tower
- `smart-cluster.jpg` - Foto untuk Instalasi Perangkat dan Aplikasi (Smart Cluster)

Format yang disarankan:
- Ukuran: 1200x900px atau lebih besar (akan di-resize otomatis)
- Format: JPG atau PNG
- Rasio: 4:3 (landscape)

Jika foto tidak ditemukan, sistem akan menampilkan gradient placeholder.
