- `yudie-rahman.jpg` - Foto Yudie Rahman (Komisaris & CEO)
- `vendra-vandoko.jpg` - Foto Vendra Vandoko Subagio (COO)
- `buddy-sanjaya.jpg` - Foto Buddy Sanjaya (CEO MIT)

Jika foto tidak ditemukan, sistem akan menampilkan placeholder dengan inisial nama.
